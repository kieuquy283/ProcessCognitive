# Exploratory diagnostic — StudentBench GRE Quantitative (24 Oct 2026)

## Research question

After controlling detailed prior proficiency and practice, do tutoring dialogue text and ordered event transitions improve independent post-test correctness predictions?

## Data & protocol

- **Dataset:** [StudentBench](https://huggingface.co/datasets/handshake-ai-research/studentbench), GRE Quantitative AI tutoring, 13 model configurations.
- **Sample:** up to 55 sessions per tutor selected from public repository directories. 715 selected; 702 downloaded completely. The 13 download failures mean this is an **availability-conditioned convenience sample**, not necessarily representative.
- **Outcome:** each response correctness to independent post-test question; 18,954 labels over 702 sessions.
- **Development:** 552 sessions, 14,904 item labels, 4-fold session-grouped OOF predictions; 150 session holdout excluded from all training/evaluation here.
- **Baseline:** pre-test score and theta; correctness of *matched pre-test item pair*, pretest skill/subskill correctness, posttest question identity, form, difficulty, item format and AI tutor; structured practice. No posttest time-spent/answer changes enter features.
- **Other features:** message counts; event counts; chronological event transition proportions; shuffled-order event transitions; TF-IDF student text, tutor text or both. All use regularized Logistic Regression. See [script](../experiments/item_trace_diagnostic.py).

## Interpretation

Practice yields a modest positive point estimate but the confidence interval includes zero. Adding more expressive raw features generally degrades regularized logistic predictive performance. **These results do not establish semantic or temporal information is useless:** TF-IDF is a lexical representation, not a frozen semantic encoder; transition counts are not a GRU or full contextual sequence model. A negative benchmark is relevant scientific evidence nonetheless.

## Critical limitations / reviewer concerns

1. **No independent held-out test assessed:** selecting features, C=.5, feature dimensions etc. on the development data precludes confirmatory claims.
2. The downloaded sessions constitute **702/715 requested** from a sample of 55 per tutor, not all 1,139 Quantitative sessions.
3. Same question bank and AI tutor arms recur between folds; the estimand is **new session on seen GRE assessment bank**, not unseen exam item or unseen tutor.
4. **Temporal control design is imperfect:** shuffled transition vector is generated by a fixed-length seed and not conditioned on the full event pattern beyond counts, so absence of uplift cannot universally rule out ordering effects.
5. No nested tuning or multiple-comparison correction. Bootstrap uncertainty is conditional on cross-validation-generated predictions, not fully nested model selection uncertainty.
6. Data include tutor-specific instructional responses, potentially recapitulating pretest weaknesses; full pretest prompt context should eventually be included in a comprehensive reference baseline.
7. Some `OPEN` practice problem answers receive automatic credit for genuine attempts; aggregate practice correctness is not necessarily a pure mastery label.
8. Conversation text truncated to 9,000 student characters and 12,000 AI characters. Long-session tail content can be lost.
9. The **script** runs on a local official StudentBench download and uses a deterministic 55-per-tutor directory sample. Because this observed run experienced remote download failures, local results on complete files may differ slightly from these numbers.

## Next falsification stage

Implement frozen semantic embeddings (e.g. SentenceTransformers, with caching and length-aware chunk pooling) against the same detailed baseline. Then assess event-sequence GRU vs event bag on the same input modalities and with shuffled-order negative controls; prefer a small model and nested hyperparameter selection. Confirm only once on the held-out sessions after feature/model choices are finalized.
