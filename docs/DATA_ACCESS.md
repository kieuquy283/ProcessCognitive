# Data access

Use the public StudentBench release following its original license, README and data dictionary:

- https://huggingface.co/datasets/handshake-ai-research/studentbench
- https://github.com/Handshake-AI-Research/studentbench

Never commit downloaded participant/session records, full tutoring transcripts, credentials or study data. Keep local datasets under `data/` and scripts under `experiments/`. Report code commit hash, dataset revision, split seed and processing inclusion criteria when presenting results.
