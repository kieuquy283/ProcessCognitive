# Research status

**Status: exploratory pilots only.** This project investigates whether learning traces add predictive signal beyond pretest and practice outcomes for independent GRE posttest correctness. Existing diagnostics compare structured baseline models, TF-IDF on dialogue, and rudimentary event-sequence representations.

Reported improvements are small, and several uncertainty intervals include zero; thus no novel cognitive-state representation, causal result, or confirmed sequence contribution has been established. The next milestone is a frozen dataset revision and evaluation with matched pretest items, semantic embeddings, and genuine temporal models.

Source: [StudentBench](https://github.com/Handshake-AI-Research/studentbench). Do not commit raw participant data.
