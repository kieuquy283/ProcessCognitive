# ProcessCognitive

Research workspace for learning-trace analysis and predicting independent post-tutoring performance using [StudentBench](https://huggingface.co/datasets/handshake-ai-research/studentbench).

## Research status

Exploratory baselines and controlled evaluations are under development. The reported pilot results are **not final held-out test results**, and do not establish causal effects of AI interaction.

## Data policy

Do **not** commit raw tutoring conversations, participant-level records, private data, downloaded datasets, API keys, or model caches. Fetch the public dataset following its official documentation, and use `.gitignore` to keep local data out of version control.

Experiments and reports are proposed on feature branches and reviewed before merging.
